# 🌸 Iris Visualization Project

This is a simple and beginner-friendly project to visualize the famous Iris flower dataset.  
It is created using Python in **Google Colab**, and uses popular libraries like Pandas, Matplotlib, and Seaborn for data visualization.

---

## 📌 What is This Project About?

The Iris dataset contains measurements of 3 different species of iris flowers (Setosa, Versicolor, Virginica).  
In this project, we explore and visualize this dataset to understand patterns and relationships between the flower features.

## 🚀 How to View or Run This Project

### ✅ Option 1: View it on Google Colab (Recommended)
1. Open the notebook file: [`iris_visualization.ipynb`](./iris_visualization.ipynb)
2. Click on **"Open in Colab"** if you're viewing from GitHub.
3. Make sure you're logged into your Google account.
4. Click **Runtime > Run all** to execute all cells and see the visualizations.

### ✅ Option 2: Run Locally (if you prefer)
1. Download the `.ipynb` file from GitHub.
2. Open Jupyter Notebook or VS Code with Jupyter extension.
3. Install required libraries:
   ```bash

📊 About the Iris Dataset
150 flower samples

4 features: Sepal Length, Sepal Width, Petal Length, Petal Width

3 species: Setosa, Versicolor, Virginica

This dataset is built-in with the sklearn library or available from public sources like UCI ML Repository.
